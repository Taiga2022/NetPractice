03 / DEVICES

直接接続・Switch・特別な住所

Switchが増えても町は分かれません。町を分ける境界になるのはRouterです。

🔌

直接接続

2台を同じネットワークにします。2台だけで話すならGatewayは不要です。

A .10/24 ── B .20/24

🔀

Switch

同じネットワークに参加できる台数を増やします。Switchを挟んでもIPの計算方法は変わりません。

🔁

Loopback

127.0.0.1は自分自身を指す特別な住所です。別のHostへの通信には使えません。

直接接続 Switch経由 A ───────── B A ─┐ ├─ Switch ─ C B ─┘ どちらも同じルール：同じNetwork部、重複しないHost部
04 / ROUTER

同じ町なら直接、違う町ならルーター

送信先 192.168.1.20（自分と同じ /24） PC ───────────────────────────→ 相手へ直接 送信先 192.168.2.20（自分とは別の /24） PC ───→ Default Gateway ───→ 別の町へ

正しいゲートウェイ

PC 192.168.1.10/24
GW 192.168.1.1

同じ町なので、まずルーターまで届きます。

届かないゲートウェイ

PC 192.168.1.10/24
GW 10.0.0.1

最初の郵便局が別の町なので、そこへ渡せません。

05 / ROUTING TABLE

ルーティング表は道案内

「この町へ行く荷物は、隣の誰に渡すか」を書きます。Next hopは、直接届く隣のルーターです。

192.168.10.0/24 10.0.0.0/30 192.168.20.0/24 PC-A ─── R1 (.1) ───────── (.2) R2 ─── PC-B │ │ └─ 192.168.20.0/24 └─ 192.168.10.0/24 → 10.0.0.2 → 10.0.0.1 行きの道だけでなく、帰りの道も必要！

デフォルトルート

0.0.0.0/0 → 次のルーター

ほかの案内に一致しない荷物を、まとめて同じ方向へ送ります。

NetPracticeでの順番

ルートは上から調べ、最初に一致したものを使います。defaultは何にでも一致するため、複数行ある場合は最後に置きます。

実際の一般的なIPルーティングでは、通常は最も具体的な経路（長いPrefix）が優先されます。

06 / LEVEL 4 & 5

Level 4からLevel 5へ

Level 4は「住所の範囲を重ねない」、Level 5は「別の町への行き方と帰り方を教える」問題です。

Level 4：Routerの別ポートと重ねない

.0 ─────── .127 | .128 ─────── .191 | .192 ─────── .255 R2: /25 Switch側の空き /26 R3: /26 Switch側の設定例 A1 82.180.118.132/26 B1 82.180.118.190/26 R1 82.180.118.129/26 Network .128 / Hosts .129～.190 / Broadcast .191

A1・B1・R1は同じSwitch上なので同じサブネットにします。ただし、RouterのR2・R3が使う範囲とは重ねません。

Level 5：Routeで往復させる

A ─── R1 ｜ Router ｜ R2 ─── B AのRoute BのRoute default → R1のIP default → R2のIP 往路：A → R1 → Router → R2 → B 復路：B → R2 → Router → R1 → A

Destinationは「どのネットワークへ」、Gatewayは「最初に誰へ渡すか」です。Gatewayには必ず、自分と直接つながり、同じサブネットにいるRouterのIPを指定します。

07 / PLAYBOOK

問題を解く順番

ネットワークを色分け
ルーターの接続口を境界に、各LANとルーター間リンクを別の町として分ける。
各町の範囲を計算
ネットワーク、最初のホスト、最後のホスト、ブロードキャストを書く。
同一区間の住所をそろえる
同じケーブル周辺は同じサブネット。重複と両端の禁止アドレスを避ける。
PCの出口を設定
デフォルトゲートウェイには、同じLANにいるルーターのIPを指定する。
未知の町へのルートを追加
宛先はネットワークアドレス、Next hopは直接つながる隣のルーター。
指で往復を追跡
送信元→宛先だけでなく、宛先→送信元の返事も一歩ずつ確認する。

192.168.5.70/27 のネットワークアドレスは？

192.168.5.64
/27の区画は32。区切りは 0, 32, 64, 96…なので、70は64〜95に入ります。BCは.95、ホストは.65〜.94です。
